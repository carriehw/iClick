The one-sentence finding

Where value leaks
YesStyle wins the recommendation — and then loses the reassurance.

AI assistants recommend YesStyle for selection and global reach. The moment a shopper asks a follow-up — is it legit, how long will it take, can I return it — the same AI hedges on delivery timelines, whether the product matches its description, and customer service. That hedge is the last thing the shopper reads before deciding.

Why this is fixable
AI caveats are not opinions — they summarise whatever public sources are reachable. Which sources this AI reached is not recorded in this run. What is measured: of the seven subjects it hedges on, YesStyle's own public files answer one. Publish the authoritative answer in structured form. Make it crawlable. Re-measure monthly.

What the comparison shows YesStyle returns the fewest reassuring answers of the four: 1 of 8, against 6 of 8 for Jolse. Set against Jolse question by question, YesStyle's answer is the weaker one on 5 to 6 of the 8 and the stronger one on at most 1; against Stylevana that margin is 1 to 2. Stylevana sits level with YesStyle rather than behind it, so this is a category-wide trust gap that two of the four have closed.
Three limits on reading this One engine, one run, 8 questions per brand. At that size the positive-only counts are not statistically separable — only the positive-or-neutral column is, and only against Jolse. The comparison also flatters the smaller competitors: this AI volunteers uncertainty about 4 of the 8 Jolse questions and none of the 8 YesStyle ones, and raises 31 concerns about Jolse against 66 about YesStyle. The brand it hedges least about is also the one it knows least about. One control did pass: the 2 questions that invite complaints score zero positive for all four brands, so the spread is not an artefact of how the questions are worded.

What this layer can and cannot tell you Everything above is a public file, fetched directly and reproducible. Whether a named AI crawler is actually served or refused at your edge is a separate question, and it cannot be answered from outside: your CDN validates a crawler by source IP, so any external probe measures the prober rather than the crawler. Settling it needs one export from your side — Cloudflare bot-management or firewall-event logs filtered to verified crawler traffic. We would rather say that than publish a number we cannot stand behind.
The opportunity Your llms.txt already does the hard part: it exists, it is well-formed, and your closest competitor has none. Today it sells the catalogue. The six unanswered themes above are what a shopper asks an AI immediately before buying, and adding them is a content edit to a file you already control.

How this report is produced

Five steps, in order. Each one is built so a sceptical reader can rerun the method and audit every figure against the retained evidence. AI answers are non-deterministic, so a rerun tests whether the finding holds, not whether the wording repeats.

01
Freeze the question set
25 prompts written in a shopper's own words, fixed before the first run so that every future month is comparable rather than merely new.
02
Ask the assistant live
Each prompt goes to the AI the way a real user would send it. The complete response text is captured and kept on file.
03
Detect brands mechanically
Alias string matching over the returned text. No model is ever asked whether a brand was mentioned, so the count cannot drift with the model's mood.
04
Audit the stance, text-bound
An auditor reads only the captured text and must return the verbatim sentence that supports its verdict. A verdict without a quote is discarded.
05
Probe the source layer
The public files that govern AI access — robots.txt, llms.txt and the declared sitemaps — are fetched for the domain and for a competitor, so a visibility result can be read against the signals behind it.
Why the full engagement runs five engines Each engine reads a different corpus, so each answers differently. An assistant that fetches pages live depends on whether your domain answers its crawler; one that answers from a search index depends on what that index already holds. YesStyle is named in all 13 unprompted prompts in this sample. Which sources that visibility rests on is not measured here - this run records the answers, not the pages behind them. Running all five is how you learn which engines carry that risk and which do not.
